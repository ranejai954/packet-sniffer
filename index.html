🚀 Run Real Packet Sniffer on Your Machine

⚠️ Note: The demo above shows simulated traffic. For real packet capture, run locally with admin privileges. 
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/packet-sniffer.git
cd packet-sniffer

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the application
sudo python sniffer.py   # Linux/Mac (requires sudo)
# OR
python sniffer.py        # Windows (Run as Administrator)

# 4. Open browser and go to:
http://localhost:5000

📋 Requirements

  • ✅ Python 3.7 or higher
  • ✅ Administrator/root privileges (for packet capture)
  • ✅ Network interface with internet traffic

🔧 Technologies Used

  • Backend: Python, Flask, Scapy
  • Frontend: HTML5, CSS3, JavaScript
  • Real-time: WebSocket (Socket.IO)
  • Data Format: JSON, CSV, TXT

💾 Export Formats Available

  • 📄 JSON - Structured data for programming/APIs
  • 📊 CSV - Open in Excel, Google Sheets, or any spreadsheet app
  • 📝 TXT - Human-readable format for logs
